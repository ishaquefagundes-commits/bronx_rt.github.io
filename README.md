# bronx_rt.github.io
O Simulador Genético é uma ferramenta educacional interativa desenvolvida para simplificar o aprendizado da Primeira Lei de Mendel. Crie uma família virtual escolhendo as características físicas do pai e da mãe e descubra instantaneamente a probabilidade genética de cada traço herdado pelo filho através do Quadrado de Punnett gerado em tempo real.
